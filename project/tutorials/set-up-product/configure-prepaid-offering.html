Configure an Offering

Offering entities represent different variations of the service offered within the Partner. For example, if you want to target your services to individual and business customers, your Phone Service Partner can have two Offerings: Residential Phone Line and Business Phone Line.

Before you start

Before proceeding with configuring your Offering, make sure to:

  • Configure your Partner entity.

  • Define the Offering type you need.

After the Offering is created, it is impossible to change the Offering type.

Offering Configuration

You must complete the Offering configuration manually via Swagger since this API is intended for manual actions only.

Step 1: Authorize in Swagger

If you are still authorized in Swagger after registering your Partner entity, you can skip this step and proceed with creating an Offering.

To proceed, you need to authorize in the Backend API Swagger using your Active Directory credentials. Read more here.

Step 2: Create an Offering

  1. Prepare a payload according to the CreateSubscriptionOffering (for a subscription Offering) or CreateSinglePurchaseOffering (for a single-purchase Offering) example in the /offering/create API endpoint and send the request.

    To see all available examples in the API specification, click on the Example dropdown.

    Pay attention to the request schema in the API specification since it describes the fields you need to pass and their meaning.

  2. Keep the following data from the endpoint response since you will need it in the next steps:

    1. id field value - a unique identifier of your Offering entity

    2. slug field value - a unique human-readable identifier of your Offering entity.

Checklist

Once completed, you should have:

  • A registered Offering entity

  • Your Offering entity ID

  • Your Offering entity slug

To double-check it, follow these steps:

  1. Authorize with your Active Directory credentials in the Backend API Swagger.

  2. Send a request to the /offering/list API endpoint.

  3. Find your Offering in the list.

To limit the list to Offerings associated with your Partner entity, pass your Partner identifier (partnerId or partnerSlug) in the request filters.

Next Steps
