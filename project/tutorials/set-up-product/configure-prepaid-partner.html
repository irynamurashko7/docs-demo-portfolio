Configure a Partner

The Partner entity represents the service you intend to offer your customers in the Project ecosystem (for example, a Phone Service Partner allowing customers to get phone lines for voice communication).

You must complete the following step manually via Swagger since this API is intended for manual actions only.

Before you start

Before proceeding with these tutorials, make sure to:

  • Check the following documentation:

    • Project Architecture documentation: to learn about the authorization, transport, and other services used in our microservice solutions.

    • Introduction: to learn what the Core Platform is and its role in the Project ecosystem.

  • Obtain access according to this document.

Register your Partner entity

After the Partner is created, it is impossible to change its slug.

  1. Authorize in the Backend API Swagger using your Active Directory credentials. Read more here.

  2. Prepare a payload according to the example in the /partner/create API endpoint and send the request.

    To see all available examples in the API specification, click on the Example dropdown.

    Pay attention to the request schema in the API specification since it describes the fields you need to pass and their meaning.

  3. Keep the following data from the endpoint response since you will need it in the next steps:

    1. id field value - a unique identifier of your Partner entity

    2. slug field value - a unique human-readable identifier of your Partner entity.

Checklist

Once completed, you should have:

  • A registered Partner entity

  • Your Partner entity ID

  • Your Partner entity slug

To double-check it, send a request to the /partner/list API endpoint and find your Partner in the list.

Next Steps
