Create an Offering

This endpoint description serves solely to show an API specification structure.

Yet, the best practice is to use API documentation tools (e.g., Swagger) to produce an automatically generated specification.

Creates a new Offering entity for a Partner. Read more about Offerings here.

Method

POST

Path

/offering/create

Auth

Active Directory credentials (Backend API)

Request

Field Type Required Description

name

string

Yes

Display name of the Offering.

1-100 characters.

Application areas:

  • Shown to customers on Project pages when the Core Platform cannot retrieve its localization resource.

  • Used to generate the Offering slug, which will be used in customer-facing URLs and UI fragment configuration.

partnerId

string (UUIDv4)

Yes

The id of the Partner entity to which this Offering belongs.

type

enum

Yes

Offering type. Determines which billing behavior applies to this Offering.

Cannot be changed after creation.

Possible values:

  • SUBSCRIPTION - customer gets access on a regular (subscription) basis

  • SINGLE_PURCHASE - customer gets access once and uses it indefinitely

  • USAGE_BASED - customer pays later for the actual usage

Read more here.

description

string

No

Internal description of the Offering.

Not shown to customers.

Up to 500 characters.

Example requests

CreateSubscriptionOffering
{
  "name": "Business Phone Line",
  "partnerId": "2b6efdca-3a92-415f-b819-1d0d4df1eae2",
  "type": "SUBSCRIPTION",
  "description": "Recurring phone line service for business customers"
}
CreateSinglePurchaseOffering
{
  "name": "Voicemail Setup Fee",
  "partnerId": "2b6efdca-3a92-415f-b819-1d0d4df1eae2",
  "type": "SINGLE_PURCHASE",
  "description": "One-time setup fee for voicemail configuration"
}
CreateUsageBasedOffering
{
  "name": "Pay-per-minute Long Distance",
  "partnerId": "2b6efdca-3a92-415f-b819-1d0d4df1eae2",
  "type": "USAGE_BASED",
  "description": "Billed according to actual minutes used"
}

Response

201 Created on success.

Field Type Description

id

string (UUIDv4)

Unique identifier of the created Offering entity. Use this for subsequent update, retrieve, and delete calls, as well as when creating associated pricing plans.

slug

string

Unique, human-readable identifier of the Offering generated from name. Used in customer-facing URLs and UI fragment configuration.

name

string

The submitted display name of the Offering.

description

string

The submitted internal description of the Offering.

partnerId

string (UUIDv4)

The submitted id of the Partner entity to which this Offering belongs.

type

enum

The submitted Offering type.

Possible values:

  • SUBSCRIPTION - customer gets access on a regular (subscription) basis

  • SINGLE_PURCHASE - customer gets access once and uses it indefinitely

  • USAGE_BASED - customer pays later for the actual usage

Read more here.

status

enum

Defines whether the Offering is active and customers can purchase it.

Possible values:

  • DRAFT - only the owner team of the associated Partner entity can see the Offering

  • ACTIVE - customers see the Offering and can purchase it

  • INACTIVE - customers do not see the Offering

New Offerings are created as DRAFT until explicitly activated.

multipleQuantity

boolean

Enables/disables the possibility to purchase several equal items associated with your Offering.

Possible values:

  • true - customers can purchase several equal items

  • false - customers cannot purchase several equal items (e.g, add the same phone number several times)

Defaults to false. Can be changed later (see Update an Offering document).

categoryIds

array of strings

id values of the categories to assign this Offering to. Used to group items of the Project pages.
Empty array means that none were assigned.
Categories can be added or removed later. Read more here.

createdAt

string (ISO 8601)

Timestamp when the Offering was created.

Errors

Status Code Meaning

400

VALIDATION_ERROR

A required field is missing, or the type is not one of the allowed values. The response body includes a details array naming the affected field(s).

401

UNAUTHORIZED

The Active Directory credentials are missing, expired, or invalid.

404

PARTNER_NOT_FOUND

No Partner entity exists with the given partnerId.

409

SLUG_CONFLICT

The generated slug already exists for this Partner. Set a different name for this Offering.
