High-Level Shopping Cart flow

This diagram uses the BPMN 2.0 standard and notation. See the BPMN reference guide here.

The Shopping Cart flow consists of the following stages:

  1. Adding Items to the Shopping Cart

  2. Reviewing the Shopping Cart

  3. Supplementing Cart Item Data (optional)

  4. Validating Order (optional)

  5. Processing Order

Stage 1: Adding Items to the Shopping Cart

The flow starts when the Partner adds one or more products to the Shopping Cart using the Core Platform SDK, and then redirects the customer to the Shopping Cart.

After that, the flow proceeds to Stage 2: Reviewing the Shopping Cart.

Stage 2: Reviewing the Shopping Cart

The Core Platform shows the list of added items in the Shopping Cart to the customer.

After the customer clicks Proceed, the Core Platform tries to call the Item Check Webhook to check whether additional data is required for any of the items in the cart.

Depending on the result, the following scenarios are possible:

  • Webhook is not set up/responds that no additional data is required: the Core Platform proceeds directly to Stage 5: Processing Order.

  • Webhook requests additional data: the flow proceeds to Stage 3: Supplementing Cart Item Data.

Stage 3: Supplementing Cart Item Data (optional)

At this stage, the Core Platform requests the missing data from the customer.

The customer reviews the order details and enters the required data. After the customer clicks Buy now, the flow continues to Stage 4: Validating Order.

Stage 4: Validating Order (optional)

Validating Order stage is used to validate the data provided by the customer.

The Core Platform tries to call the Validation Webhook to check whether the data is valid.

Depending on the result, the following scenarios are possible:

  • Webhook is not set up/responds that the data is valid: the flow proceeds to Stage 5: Processing Order.

  • Webhook responds that the data is not valid: the flow returns to Stage 3: Supplementing Cart Item Data.

Stage 5: Processing Order

Once the order data is validated, the Core Platform creates an order, charges the customer, and tries to call the Order Processing Webhook to check whether the order was processed successfully.

Depending on the result, the following scenarios are possible:

  • The order was processed successfully: the Core Platform processes the order items and closes the order.

  • The order was not processed successfully/the webhook is not set up: the Core Platform refunds unprocessed items and closes the order.

After that, the Core Platform shows the order summary to the customer.
